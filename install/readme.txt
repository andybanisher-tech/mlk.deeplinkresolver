# DeepLink Resolver (mlk.appdeeplinkresolver)

Модуль для 1С-Битрикс «Управление сайтом» позволяет настраивать правила преобразования публичных URL сайта в диплинки для мобильных приложений или внешних систем.

## Возможности

- Задание правил резолвинга на основе **шаблонов URL с плейсхолдерами** (например, `/catalog/{product}.html`)
- Поддержка **опциональных сегментов** через `{*}` (захват любого количества символов)
- **Автоматический режим** диплинка: выбор из поля или пользовательского свойства элемента/раздела инфоблока
- **Ручной режим** диплинка: формирование по шаблону с подстановкой:
  - значений плейсхолдеров из URL (`{product}`, `{category}` и т.д.)
  - `{source}` – значение выбранного поля/свойства элемента/раздела
  - `{element_id}`, `{section_id}`, `{iblock_id}`
- **Гибкое сопоставление** плейсхолдеров с полями или свойствами инфоблока
- **Отдельный API-эндпоинт** без конфликта с существующими обработчиками
- **Экспорт и импорт** правил в формате JSON
- **Режим отладки** (`debug=1`) для диагностики

## Требования

- 1С-Битрикс: Управление сайтом версия **20.0.0** и выше
- PHP 7.4 – 8.4
- Установленные модули: `main`, `iblock`

## Установка

### Через Маркетплейс (рекомендовано)

1. Перейдите в раздел «Маркетплейс» → «Каталог решений»
2. Найдите «DeepLink Resolver»
3. Нажмите «Установить»

### Ручная установка (для разработки)

1. Скопируйте папку `mlk.appdeeplinkresolver` в `/bitrix/modules/`
2. Перейдите в «Настройки» → «Настройки продукта» → «Модули»
3. Найдите модуль «DeepLink Resolver» и нажмите «Установить»

## Настройка правил

После установки перейдите в **Настройки → DeepLink Resolver**.

### 1. Добавление правила

Нажмите «Добавить правило».

### 2. Основные параметры

| Поле | Описание |
|------|----------|
| Активность | Включить/отключить правило |
| Сортировка | Порядок применения (меньше – раньше) |
| Название правила | Внутреннее имя |
| Шаблон URL | Пример: `/catalog/{product}.html` или `/catalog/{category}/{*}` |
| Сопоставление плейсхолдеров | Для каждого плейсхолдера укажите, в каком поле/свойстве искать значение |
| Тип объекта | Элемент или раздел инфоблока |
| Инфоблок | Выберите инфоблок, в котором хранятся данные |
| Тип контента | Строка, возвращаемая в ответе API (например, «товар», «категория») |

### 3. Режим формирования диплинка

#### Автоматический режим
- Выберите поле или свойство, значение которого станет итоговым диплинком.
- Пример: поле `DETAIL_PAGE_URL` или свойство `UF_DEEPLINK`.

#### Ручной режим
- Включите «Ручной (шаблон с подстановкой)»
- Задайте шаблон диплинка, используя плейсхолдеры:
  - `{source}` – значение выбранного поля/свойства
  - `{element_id}` или `{section_id}` – ID найденного объекта
  - `{iblock_id}` – ID инфоблока
  - любые плейсхолдеры из шаблона URL (например, `{product}`)
- Пример: `/app/product/{source}?id={element_id}`

## Использование API

Эндпоинт: `/bitrix/tools/mlk.appdeeplinkresolver/resolve.php`

### Параметры

| Параметр | Тип | Обязательный | Описание |
|----------|-----|--------------|----------|
| `url` | string | Да | Абсолютный или относительный URL (начинается с `/`) |
| `debug` | int | Нет | 1 – включить отладку (возвращает диагностику) |

### Пример запроса

```bash
curl -X POST "https://ваш-сайт.ru/bitrix/tools/mlk.appdeeplinkresolver/resolve.php" \
  -d "url=/catalog/socolor-pre-bonded-90-ml.html&debug=1"
